# Roadmap

This is a direction, not a commitment. Priorities can change based on feedback.

## Now

- Windows release with checksums and SmartScreen guidance.
- macOS notarization so the macOS build opens without manual steps.

## Next

- Windows code signing to remove the SmartScreen warning.
- Recovery workflow and performance improvements.
- Translation and screenshot updates for every supported language.
- More comparison and troubleshooting content on the website.

## Later

- Microsoft Store listing.
- Additional distribution channels.
- Further format coverage, if there is demand.

Have a request? Open a feature request using the issue template.
