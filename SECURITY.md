# Security policy

## Supported versions

Only the latest public release receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Email **security@pwdone.com** with `SECURITY` in the subject and include:

- PwDone version and operating system.
- A description of the issue and its impact.
- Steps to reproduce, if possible.
- Any relevant logs with personal paths and file names removed.

You can also use GitHub's private vulnerability reporting from the repository's
**Security** tab.

**Do not include** encrypted files, passwords, recovered passwords, license
keys or any personal data.

We aim to acknowledge reports within 3 business days and will keep you updated
on the fix and disclosure timeline.

## Scope

This policy covers the PwDone desktop application, the installers published on
`pwdone.com`, and the website itself.

## Third-party components

PwDone bundles Hashcat and John the Ripper. Vulnerabilities in those projects
should also be reported to their maintainers.
