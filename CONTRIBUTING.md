# Contributing

This repository is the **product hub** for PwDone, not an open-source project.
The application source code is proprietary and is not published here.

## Bugs and feature requests

- Use the issue templates.
- Include the PwDone version, operating system and file format.
- **Never attach** encrypted files, passwords, license keys or personal data.
- For security issues, follow [SECURITY.md](SECURITY.md) instead of opening an
  issue.

## Pull requests

We do not accept unsolicited code contributions. Small documentation fixes
(typos, broken links, screenshot updates) are welcome — please open an issue
first so we can agree on the change.

## Translations

README translations and localized screenshots live in this repository. If a
translation is wrong or a screenshot is outdated, open an issue with the locale
and the suggested correction.

## Conduct

Be respectful and stay on topic. Harassment, spam and promotional links are not
welcome.
