# Support

## Documentation

Start with the documentation: <https://pwdone.com/docs>

It covers installation, supported formats, recovery methods and common
questions.

## Contact

For purchases, licenses, refunds and general questions:

- <https://pwdone.com/contact>
- <support@pwdone.com>

We usually reply within one business day.

## Bugs and feature requests

Use the issue templates in this repository:

- [Bug report](../../issues/new?template=bug_report.yml)
- [Feature request](../../issues/new?template=feature_request.yml)

Please include the PwDone version, your operating system and the file format.
**Never attach** encrypted files, passwords, recovered passwords, license keys
or personal data.

## Security issues

Do **not** open a public issue. Follow [SECURITY.md](SECURITY.md) and email
<security@pwdone.com>.

## Before you ask

- Check that you are on the latest release.
- Try the SmartScreen steps on the [download page](https://pwdone.com/download)
  if Windows blocks the installer.
- For a recovery that did not find the password, include the method you chose
  (what you remembered) and the approximate length range — not the file itself.
