# Screenshots

Localized app screenshots used by the README files.

Each locale folder contains the same five workflow screenshots:

| File | Step | What it shows |
| --- | --- | --- |
| `01.webp` | File | Select an encrypted file |
| `02.webp` | What you know | What you remember about the password |
| `03.webp` | Configure | Length, characters, known parts |
| `04.webp` | Recover | Progress, speed and current candidate |
| `05.webp` | Result | Recovered password or a retry |

Locales: `en`, `zh`, `zh-Hant`, `ja`, `ko`, `de`, `es`, `fr`, `it`, `nl`, `pl`,
`pt`.

## Guidelines

- Keep the file names `01.webp` … `05.webp` and the step order.
- WebP, 1280×720 or larger, dark theme.
- Show the app UI in the matching locale.
- Remove file names, paths, license keys and any personal data.
- If a screen changes, replace the file in place; no README edit is needed.

`assets/social-preview.png` is the GitHub social preview (1280×640); replace it
in the repository settings, not in the README.
